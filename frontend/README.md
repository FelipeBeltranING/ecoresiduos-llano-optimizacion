# Frontend — React + TypeScript + Vite + Tailwind

```
src/
├── pages/        # una página por ruta del mapa de navegación (Documento Base 13.1)
├── components/   # componentes reutilizables (Botón, Tarjeta KPI, Tabla, Mapa, Gráfica…)
├── features/     # lógica por funcionalidad (empresas, rutas, exacto, genetico, sensibilidad…)
├── api/          # cliente Axios y hooks de TanStack Query
├── hooks/        # hooks compartidos (useX)
├── lib/          # utilidades (formato es-CO, validaciones Zod)
└── styles/       # tokens de la guía de estilo
tests/            # Vitest + Testing Library
```
