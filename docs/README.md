# Documentación

- `diagramas/` — diagramas en Mermaid (`.mmd`), versionados junto al código.
- `informe/` — informe técnico en formato IEEE.
- `backlog/` — backlog del producto en `backlog.json` (fuente del script `scripts/setup_github.py`).

El Documento Base del proyecto (backlog, DoR/DoD, riesgos, arquitectura, plan de pruebas)
es la línea base del proyecto.
